# Split-Canonical Publication Policy

This document is non-normative and does not declare a final release.

The split Markdown files are the canonical source and the only maintained publication form in this repository.

A single-file Markdown document may be generated on demand for local convenience using `tools/assemble_single_file.py`. Generated single-file documents are derivative convenience outputs and are not committed to the repository.

If a downloadable single-file artifact is desired later, it should be generated outside the maintained source tree or handled as a separate release artifact after an explicit decision.

This policy reduces duplicated-maintenance and stale-artifact risk by ensuring that only one source of truth (the split canonical files) exists within the repository.
